KEYBOARD SHORTCUTS HELPER — LOCAL TEST VERSION

INSTALL IN CHROME
1. Extract keyboard-shortcuts-helper.zip to a folder.
2. Open Chrome and visit chrome://extensions
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the extracted keyboard-shortcuts-helper folder.
6. Pin the extension from Chrome's Extensions menu if desired.
7. Click the extension icon to search/filter shortcuts.

NOTES
- This is an initial local testing build, not yet published.
- The extension only uses a popup and does not request browser permissions.
- The website link points to https://keyboardguides.com/.
- Review all shortcuts and descriptions before public release; behavior may vary by app or Windows version.
- Before publishing, create suitable store icons and screenshots, verify keyboardguides.com in Google Search Console, and complete Chrome Web Store listing/privacy disclosures.
